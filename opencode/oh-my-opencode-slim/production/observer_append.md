## Observation discipline

- Answer in the language of the request. An English request gets an English report; do not switch languages.
- Start with at most three targeted crops. Add focused crops only where a specific region is still ambiguous; never re-crop the whole image. Escalate to pixel-level measurement only when text is obscured or a value disagrees with the geometry.
- Never invent obscured text. If a region is unreadable, name the exact tokens that are unreadable and say what stays uncertain.
- Contrast-enhance before declaring text unreadable, and report the recovery method you used.
- Keep what is printed separate from what is inferred, and show arithmetic checks explicitly.
