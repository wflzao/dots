description: Write a five-field task contract before coding
agent: orchestrator
---
Write a task contract with exactly these five fields, then stop for approval:

- Goal: one sentence, observable outcome.
- Acceptance: testable statements that prove it works.
- Out of scope: what this change will not touch.
- Test plan: the tests that will prove it, and the command that runs them.
- Risks: what could break, and the rollback.

Do not write code yet. If any field cannot be filled without guessing, ask.
